# Reviews

Review sesje — security, code quality, UX, performance. Jedna sesja AI/manualna na plik.

## Status values

`todo` · `planned` · `in progress` · `done` · `verification needed`

## Index

| File | Summary | Status |
|------|---------|--------|

When adding a new entry: create `YYYY-MM-DD-slug.md`, add a row here.

## After each run

1. Ustaw status w tej tabeli i w pliku review.
2. Zapisz findings w sekcji **Findings** (severity + odniesienie do pliku/lokalizacji).
3. Dodaj lub zaktualizuj wiersze w [issues/README.md](../issues/README.md) dla actionable follow-ups.
